文字数カウンター

文章を入力すると、文字数や単語数などをリアルタイムで集計します。

入力待ち 0 bytes

集計結果

リアルタイム更新
文字数0空白・改行を含む
空白を除く0スペース・改行を除外
単語数0日本語・英語に対応
行数0改行で区切った行
段落数0空行で区切った段落
バイト数0UTF-8換算

このツールについて

入力した文章の文字数、空白を除いた文字数、単語数、行数、段落数、UTF-8でのバイト数をリアルタイムで数えます。

文字数は絵文字や結合文字もできるだけ人が認識する1文字単位で数えます。単語数は日本語などの分かち書きに対応したブラウザ機能を利用します。

入力内容はブラウザ内で処理され、サーバーへ送信されません。
